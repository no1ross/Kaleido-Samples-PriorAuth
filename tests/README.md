# Tests

Test projects for the sample go here, one folder per project (e.g. `tests/Kaleido.Samples.PriorAuth.UnitTests`),
and are added to the solution and to `Kaleido.Samples.PriorAuth.CI.slnf` so CI runs them.

The sample has no .NET test project yet. The UI's tests live with the app (`ui/src/**/*.spec.ts`,
`npm test` in `ui/`).
